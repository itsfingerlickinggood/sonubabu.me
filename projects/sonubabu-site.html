Live website

sonubabu.me

A deliberately small static portfolio with research writing and lightweight visualizations.

Architecture

The site uses semantic HTML, modular CSS, and vanilla JavaScript. A small Node build script concatenates CSS and invokes command-line minifiers for CSS and JavaScript. Vercel rewrites preserve extension-free public URLs.

Interface

The design uses system fonts for the core interface and an article font on some long-form pages. It includes a persisted light/dark theme, responsive layouts, keyboard focus styles, reduced-motion-aware CSS, and canvas-based decorative visualizations.

Content discipline

This revision adds status labels and source boundaries throughout the site. Completed studies, pilots, prototypes, concepts, and proposals are no longer presented as interchangeable forms of evidence.

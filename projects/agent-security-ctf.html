Agent-Security Challenge Report

A sanitized account of six completed advanced and expert levels in an intentionally vulnerable ARKX agent environment.

Scope

This work concerns a private, intentionally vulnerable CTF. It is not presented as exploitation of production systems, discovery of CVEs, or evidence of zero-day vulnerabilities.

Documented findings

Challenge areaSecurity theme
Calculator toolUnsafe expression evaluation and unintended local-file access
MCP serverExposed resources and tools across a weak trust boundary
Connectivity toolCommand injection and log-mediated disclosure
Configuration parserUnsafe YAML deserialization
Multi-agent workflowShared cache/session authorization-state poisoning
Trading workflowTOCTOU race and double spending

Method

For each level, I mapped agent roles, reachable tools, mutable state, validation behavior, and output side channels. I recorded failed and successful probes, reduced the exploit to reproducible steps, and connected the behavior to its underlying software or authorization failure.

Reporting

The completed report was prepared on 25 June 2026 and includes evidence, reproduction paths, root-cause analysis, impact and severity discussion, mitigation proposals, and tentative framework mappings. Because the source is private, this page publishes only high-level vulnerability classes and omits flags, payloads, reusable identifiers, and detailed transcripts.

Evidence boundary

The report directly supports completion of the six assigned levels and the technical work above. Leaderboard rank and score require separate leaderboard evidence, so they are not used on this page.

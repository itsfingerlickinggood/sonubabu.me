Independent product · 2025–2026

market01

A GPU-market intelligence product built to make provider inventory and pricing easier to compare.

Product scope

market01 aggregated GPU listings from multiple providers into a normalized inventory with structured search, ranking, comparison views, pricing alerts, watchlists, and APIs. A recorded product snapshot covered more than 6,500 listings across 43 providers.

The public description is intentionally tied to that snapshot. It does not turn traffic counts, performance targets, or planned recommendation features into permanent product claims.

Engineering

I led product and engineering work across interface architecture, provider ingestion and normalization, search and ranking, API integration, deployment, monitoring, and iteration. The documented stack includes Next.js, TypeScript/JavaScript, Tailwind CSS, Supabase/PostgreSQL, Cloudflare Workers, Queues, Cron and WAF, Vercel, Git, and CI/CD.

Programs and boundaries

market01 was selected for Delta Residency 2025 and participated in Cloudflare for Startups. A YC application was prepared but is not presented as acceptance. The project’s exact end/current status differs across source records, so the public date is shown only as 2025–2026.

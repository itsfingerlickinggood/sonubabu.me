Frontend demo · 2025–2026

Advanced Weather Intelligence Portal

A portfolio application exploring weather dashboards, geospatial interaction, offline-friendly UI patterns, and accessibility.

What was built

The project is a multi-route React and Vite application with forecast, air-quality, UV, trip-planning, and map-oriented interfaces. It includes protected and administrative routes, responsive dashboards, route-level code splitting, client-side caching, and accessibility options such as reduced-motion and high-contrast modes.

Data boundary

The repository is a frontend demo. Its default workflows use mock data, with adapters for optional live providers. It does not demonstrate an operational sensor network, an IMD ingestion pipeline, verified coverage of all Kerala districts, or a deployed emergency-planning system.

Implementation

The recorded stack includes React 18, Vite, TanStack Query, MapLibre, MSW, Vitest, and Testing Library. The value of the project is in interface architecture and stateful data presentation, not unsupported production or adoption claims.

Verifier-Grounded Evaluation Environment

A HUD-compatible demo that turns a synthetic AI-safety paper into an executable agent task with hidden evaluation.

Task design

The agent receives a redacted synthetic paper, public calibration/test data, and starter code. It must produce executable code, structured results, and a report. Evaluation checks method fidelity and held-out generalization rather than relying only on an LLM judge.

Evaluation controls

  • Unique temporary workspaces for task runs.
  • Hidden labels and verifier logic outside the agent workspace.
  • Fail-closed process isolation with restricted network and credential access.
  • Schema, numerical, method-fidelity, baseline, ablation, and false-positive checks.
  • Decomposed rewards and deliberately weak-solver controls.

What this demonstrates

The repository demonstrates environment engineering: packaging evidence, executable submissions, hidden tests, and reward components so that successful completion requires more than prose plausibility or grader leakage.

Limitations

This is a synthetic, unpublished-style integration demo—not a completed reproduction of a published paper, a model-training result, or evidence of deployment. Historical validation numbers appear in prior résumé material, but they were not independently rerun for this website update and are therefore omitted.
